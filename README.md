## Como rodar localmente

Não há build nem dependências — é só abrir o arquivo:

```bash
git clone https://github.com/ViniKibaa/Portfolio.git
cd Portfolio
```

Depois, abra o `index.html` direto no navegador, ou use uma extensão como **Live Server** (VS Code) para recarregamento automático.
